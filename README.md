# TCP Delivery Lab

IoT 데이터 수집과 전달 과정에서 직접 TCP 통신, MQTT, HTTP 및 MQ의 역할과 차이를 비교하는 개인 실험 프로젝트입니다.

먼저 장비와 수집 서버 사이의 TCP/MQTT 통신을 비교하고, 이후 수집 서버와 처리 서버 사이에 RabbitMQ를 도입하여 HTTP 전달 방식과 비교합니다. 연결 관리, 전달 확인, 중복 처리 및 장애 후 복구 동작을 단계별로 구현하고 검증합니다.

## 현재 구현

- Blocking TCP 서버에서 암호화된 메시지 한 건 수신 (9090 포트)
- 길이 기반 프레임 처리와 AES-192/GCM 암복호화
- 정상 수신, 잘못된 프레임 및 변조 검증 테스트

다음 단계에서는 가상 장비의 TCP 송신을 구현하고, 같은 데이터를 MQTT로 전달하며 비교합니다.

이후 RabbitMQ를 추가하여 수집 서버와 처리 서버 사이의 HTTP/MQ 전달 방식도 비교할 예정입니다. 현재는 후속 실험용 인프라 설정만 준비되어 있으며, MQ 발행과 소비 기능은 아직 구현하지 않았습니다.

## 기술

Java 17, Spring Boot 3.5.6, Gradle
